## V2 版式档案（与旧版逐条相反，先对照再动手）

- 页面 7.5×10.83 in；**每页页级背景=信头图**（`p:bg`，layout/母版无背景）——不可 strip；
  新增页若要同款信头须克隆 `p:bg` 并物化图片 rel。
- 正文框：称呼 4 run（尊敬的｜前导空格｜姓名+尾空格｜教授：）+ 开场白；
  **没有**"您好！/会议时间/会议地点"段落（旧引擎 `para_by('您好')` 直接崩）。
- 页脚：两个 GROUP（会议日期/会议地点 文本+小图标图片），**每个内容页都有**，全局替换即可。
- 任务表 3 列；**主席函=两张表**（主表 表头+1 行；尾表无表头单行，纵向紧贴堆叠）——
  主表加行后必须把尾表 `top` 下移 `ROW_H×新增行数`，尾表序号列要顺延。
- 简介页三件套：照片(1.98×2.68in)+简历框+姓名医院框；**简历行是真项目符号**
  （`marL=indent=±285750` + Arial `buChar •`），只复制行距会丢点。
- 话题页：独立页（"讨 论 问 题"大标签 + 问题文本框 18pt）。
- 主持基座 deck 现成骨架：王斌型 = 封面+5 简介页+话题页+下一位主持页；
  梁伟权型 = 封面+4 简介+话题页+4 主席团简介页（末位主持用，自带"邀请大会主席团总结"行）。
  中间简介页超过 5 张时用 `clone_slide` 同包克隆补位。

## 站点复刻七步

1. **议程权威源**：在线表为准但注意①用户给的链接锚点可能指别的站（实战：`?sheet=bVifhB`
   是成都表不是郑州表）；②revision 会涨，生成前必须重读；③合并单元格=双环节主持
   （`D11:D12` 之类）；④用户指定的海报图版本优先，海报上的地点/时间/名单与在线表互证。
2. **简历提取**（`make_bios*.py`）：`.doc/.ppt` 先 soffice 转换（逐个转，别信批量变量展开）；
   docx 直接解析 `word/document.xml`（python-docx 对部分 WPS 文件抛 KeyError）；
   pptx 文本按 `<a:p>`+`<a:br>` 拆行；**只取画布内形状**（离画布内容是别人的，李锡清页混入
   刘莹案例）；照片取画布内最大显示面积图片，**居中裁剪到 0.739 版式比例**再入库；
   文本为 0 的是扫描件 → 渲染成 PNG 后**视觉转写**（照片也从渲染图裁）。
3. **任务矩阵 + 开放问题清单**，用户确认后才生成。矩阵固定要标注：主持链条、双环节、
   首环节主持的介绍人、每场讨论配哪套问题。已知必须问的：①讨论问题套怎么配
   （系列规则：顺德=成都同套，按上一环节讲题对号）；②首环节介绍人（已定规则：最后致辞
   的主席介绍，其函加行+附简介页）；③简历信息与目录/议程冲突时署名谁（见二次审核）。
4. **生成**：`python scripts/build_v2.py station.json`；官方日程海报页按需在配置给
   `agenda_img`（白底等比居中防变形；幂等：已有大图页则跳过。2026-08 用户决定两站均不放）。
5. **审计**：`python scripts/audit_v2.py station.json`——校验点从同一份配置自动派生——页数、称呼、
   日期时间、地点、每行时间+文案、话题关键词、简介页人名（**strip 空格后匹配**，两字名
   是"张   衍"）、照片 hash 不在模板原图集合、残留名单、专项（尾表序号/位移、首主席联动）。
6. **qa_render + 渲染图逐角色抽查**：主席(普通/加长)、各主持、讲者、讨论、末页海报。
   图片型页面（海报页）被旧版判"空白页"是文本启发式误报，已修复。
7. **交付报告**：差异决策（候补不上函、医院署名冲突、共用问题套）+ 待确认清单 + 截断报告。

## 用户已定稿规范（2026-08 两站确认，勿再重复提问）

- 称呼：`尊敬的`+**前后各三个空格**+姓名+`教授：`，空格随姓名带下划线。
- 主席开场白 = "并担任**会议主席**"（不再写致辞嘉宾）；任务行仍写致辞/总结具体事务。
- 首环节主持由最后致辞的主席介绍；该主席函加行+附首主持简介页，尾表序号顺延。
- 逐拍任务表**仅主持函**：受邀/交接=精确起始时刻、环节=区间；讲者/讨论=单行区间；
  全部 HH:MM 补零（郑州站从混排改为统一补零）。
- 加粗：人名（含"您"）+角色词（演讲嘉宾/主持嘉宾/学术讨论嘉宾/总结嘉宾/会议主席）；
  讲题引号内、连接语不加粗。
- 开场白重建为**单段流式**（"……并担任会议X嘉宾。以下……供您参考。"），勿继承作者手敲
  分段；日期/时间/地点用模块全局参数化（MEET_SPAN 别写死 12:05，成都 12:00 踩过）。
- 简历行圆点+自适应行距，**目标高度到姓名框上沿**（不是文本框总高），硬上限 17 行。
- 文件命名 `NN-角色-姓名-沟通函.pptx`（序号=该人首个环节）；同名策略写进构建脚本 PREFIX 表。
- 照片用简历里提取的（用户已确认），居中裁剪到版式框比例；拿不到就删框并报告。

## 二次审核清单（生成后、交付前必做）

1. **专家信息一致性**：简历正文 vs 简历文件名 vs 议程表 的医院/职称冲突（实战：朱琰琰
   简历写河南省人民医院、目录名是河南省肿瘤医院）→ 默认采用简历原件并在交付时请用户拍板。
2. **照片归属**：多人简历页按画布内外拆分（李锡清/刘莹案例——离画布的是同事）；
   裁剪后逐张目检是否本人、清晰度可否印刷（<500px 宽的标注）。
3. **截断报告**：>17 行截断、获奖清单裁剪，逐人列名。
4. **排版复检**（渲染图）：简介页简历不得压姓名框；主席函主表加行后尾表不重叠；
   开场白无孤字、无句号起行；时间列全补零。
5. **待确认清单**随交付列出：候补人员（有简历但不在议程，如宋刚）、医院署名、
   共用问题套、双环节拆分等。
