# 模板解剖详解（A4 信函式沟通函）

以"靶握先机 HER2 全国行"系列实战模板为参照。不同会议模板参数会变，**以 analyze_template.py 的输出为准**，本文给的是"该看什么"和典型值。

## 页面

- A4 竖版：8.27 × 11.69 in（EMU 7560000 × 10692000）。不是 16:9 幻灯片。

## 信函页（每份第 1 页）三层结构

1. **整页背景图**（`p:bg` → `blipFill`）：信头（主办方 logo、会议名、装饰图）全在图里，不是可编辑文字。
   - 坑：页级背景可能与母版背景不一致（旧会议信头残留）。确认方式：解剖脚本会分别列出 slide bg 和 layout/master bg 的图片哈希，哈希不一致就必须问用户用哪张，或按正文会议名判断。
   - 去掉页级背景露出母版信头：删除 `<p:bg>` 元素并 `slide.part.drop_rel(rId)`。
2. **正文文本框**（微软雅黑 14pt、1.5 倍行距、固定高约 2.98in，y≈3.2in 起）：
   - 段落：称呼 → 开场白 → **空段** → 会议时间 → 会议地点 → （备注行，可选）→ "您的任务环节"（±冒号）→（末尾空段，视角色有无）。
   - 称呼的姓名 run 是 20pt 加粗下划线，且常被拆成多个 run。
   - **固定高度 + 150% 行距意味着每多一行内容就把尾部往下顶**：加备注行必须同步删一个空段补偿，否则"您的任务环节"压到表格上。
3. **任务表**（3 列：序号/时间/内容；列宽约 0.63/1.40/5.43in；表头与内容格 accent1 蓝半透明填充）：
   - 行类型：表头 / 篇章行（gridSpan=3 合并）/ 任务行 / 讨论话题行（前 2 列合并标签）。
   - 典型行高（EMU，杭州 0807 版实测）：表头 291893~321945；主席任务行 687731+645160；主持单行 464023、两行 932180、名单行 1266825、带交接句行 1390015；讲者/讨论任务行 1099185、篇章行 340360。
   - 行高是"最小高度"（PowerPoint 会按内容扩张），给宽不给出。

## 简介页（主持函第 2 页起）

- 无页级背景 → 显示母版信头；版式：【标签】(32pt) + 姓名 (28pt+下划线矩形) + 简历列表 (12pt, 1.5 倍行距, 最多约 17 行) + 【主题】框 (24pt, 高 1.72in——**只能放约 2.5 行**，长内容必须降字号)。
- 简历超 13 行：150%→130% 行距；超 15 行：120%；硬上限 17 行截断。
- 环节主持页没有主题框（删除）。

## 内容规范速查（用户定稿）

| 角色 | 末尾空段 | 冒号 | 加粗 |
|---|---|---|---|
| 主席 | 无 | "您的任务环节：" | 前半句粗（邀请人）+ 工作词粗 |
| 主持 | 无 | 无 | 选择性：人名 + 工作词 |
| 讲者/讨论 | 有 | 无 | 人名粗，其余正常 |

- 开场白只加粗会议名；**禁止**加主办全称括注（多一行就溢出）。
- 主持任务行两段式：交接段（"由 X 教授 介绍并邀请 您 作为本环节主持嘉宾"）+ 空段 + 任务段；任务段末尾可接" 由 您 介绍并邀请 Y 教授 作为下一个环节的主持嘉宾"。
- 讨论函话题行：每行一个话题，放在合并单元格第三列。
